# 作业一：拉格朗日插值与牛顿插值的比较

**时间安排**：4 学时

**活动内容与目标**：秉承 EIP-CDIO 的教学理念，以实验的方式，理解高阶插值的病态性，观察拉格朗日插值的龙格现象。

**任务书**：编写拉格朗日插值和牛顿插值函数，并用其计算所给函数的插值，并绘图。

**考核形式与要求**：作业验收和提交报告。

**评分标准**：根据验收和作业报告评分。

---

## 文件说明

| 文件 | 职责 |
|---|---|
| `main.py` | 入口：交互画板，按钮随机加点，拉格朗日/牛顿两条曲线同步重绘 |
| `lagrange.py` | 拉格朗日插值：基函数求值、多项式展开系数、表达式排版 |
| `newton.py` | 牛顿插值：差商表递推、嵌套乘法（秦九韶）求值 |
| `nodes.py` | 插值节点管理（在 f(x) 上随机采样、去重） |
| `original_function.py` | 实验函数 f(x) = 1/(1+x²)，区间 [-5, 5] |
| `axes.py` | 手工绘制的穿过原点的 x/y 数轴 |
| `legend_box.py` | 表格样式图例 + hover 悬浮窗显示完整多项式 |
| `docs/2024611031-黄应辉.md` | 实验报告（Markdown 源） |
| `2024611031-黄应辉.pdf` | 提交的实验报告 |

## 运行

```bash
uv run main.py                   # 交互演示（点击"随机加点"按钮）
uv run python -m doctest *.py    # 运行全部 doctest
```
